# LearnLoop AI 🌿

**LearnLoop AI** is an intelligent, personalized study planner that transforms complex course syllabi into actionable, day-by-day learning roadmaps with built-in interactive quizzes and progress tracking.

---

## ✨ Features

- 📄 **PDF Syllabus Extraction:** Upload any syllabus PDF to instantly parse and structure topics.
- 📅 **Custom Study Schedules:** Generates daily study targets based on your exam date and available hours.
- 🎯 **Topic-Wise AI Quizzes:** Dynamic multiple-choice questions generated from extracted syllabus text.
- 📊 **Detailed Result Breakdown:** Review scores, correct answers, and mistake analysis instantly.
- 📈 **Progress Dashboard:** Track completed days, remaining timeline, and overall preparation status.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Tailwind CSS, JavaScript (Vanilla), PDF.js
- **Backend:** FastAPI, Python, Uvicorn
- **AI / LLM:** Google Gemini API (`google-genai`)
- **PDF Processing:** PyPDF
